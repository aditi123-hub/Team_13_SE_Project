# Security Implementation

## Customer Registration (BMS-F-001)

Endpoint: POST /auth/register

**Required fields:**
- fullName
- email
- password
- Either mobile or governmentIdNum

**Features:**
- Email format validation
- Password minimum 8 characters
- Duplicate detection for email, mobile, government ID
- Audit logging

**Test:**
```bash
curl -X POST http://localhost:3000/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "fullName": "John Doe",
    "email": "john@example.com",
    "mobile": "1234567890",
    "governmentIdNum": "GOV123",
    "password": "password123"
  }'
```

## Password Hashing (BMS-SR-002)

- Bcrypt with 12 salt rounds
- No plaintext password storage
- No passwords in logs

Implementation:
```javascript
const saltRounds = 12;
const passwordHash = await bcrypt.hash(password, saltRounds);
```

## TLS 1.2 Enforcement (BMS-SR-001)

**Configuration:**
- Minimum version: TLS 1.2
- Maximum version: TLS 1.3
- Disabled: SSLv2, SSLv3, TLSv1.0, TLSv1.1

**Setup:**
```bash
# Generate development certificates
bash generate-certs.sh

# Start with HTTPS
ENABLE_HTTPS=true npm start
```

**Environment variables:**
```env
ENABLE_HTTPS=true
HTTPS_PORT=3443
SSL_KEY_PATH=./certs/server-key.pem
SSL_CERT_PATH=./certs/server-cert.pem
```

## Audit Log Retention (BMS-NF-004)

- Audit records include timestamps generated by the database.
- Audit records are linked using a SHA-256 hash chain to support integrity verification.
- PostgreSQL triggers prevent audit records from being deleted or modified, except for the logger's one-time final hash update.
- The minimum audit-log retention policy is five years.
- The admin audit-log API reports the minimum retention period.
- Do not introduce automatic deletion of audit records after five years; the policy specifies a minimum retention period.
- Run the backend test suite with `npm test` from the `backend` directory.

**Operational note:** Database backup and recovery procedures must preserve audit records to maintain retention and audit-chain integrity.
